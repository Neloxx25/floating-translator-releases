# Floating Translator — релизы

Плавающий переводчик DE ⇄ RU для Windows: живые субтитры, словарь с повторением слов.

## Установка

1. Откройте [**последний релиз**](../../releases/latest) и скачайте **`Translator-<версия>-win64.zip`** (~1,5 ГБ).
2. Распакуйте архив.
3. Запустите **`Install.cmd`**. Переводчик установится, появятся ярлыки «Переводчик», включится автозапуск.

Обновления потом приходят сами: правый клик по иконке → «Проверить обновления».

Файл `app.asar` в релизах нужен для автообновления, скачивать его вручную не нужно.
